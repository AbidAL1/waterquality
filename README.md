# WaterWatch UP — Water Quality Intelligence Dashboard

**Project:** AI-Enhanced Drinking Water Quality Monitoring in Rural Eastern UP  
**Institution:** IIIT Allahabad | **Funding:** CST-UP / DST  
**Researcher:** Abid (JRA) | **PI:** Dr. Saurabh Mishra

## Features
- Real interactive map (OpenStreetMap + Leaflet.js) — no API key needed!
- 27 districts plotted with actual GPS coordinates
- Click any marker → water quality popup with BIS comparison
- Filter buttons: All / Districts / Blocks / Field Sites
- 8 dashboard pages: Overview, Map, District/Block/Village clustering, Sites, Parameters, Diseases, AI Intel

## Deploy to Vercel (3 steps)
1. Upload this folder to GitHub (New repo → upload files)
2. Go to vercel.com → New Project → Import your GitHub repo
3. Click Deploy — your URL will be: yourname.vercel.app

## Local Preview
Just open index.html in any browser — works offline!
